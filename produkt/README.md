# Personlig finance tracker

Det produkt, softwarefabrikken bygger. Alt i denne mappe er lavet af kodeagenten via issues og pull requests.

**Vision:** et lille program, hvor jeg kan registrere indtægter og udgifter, kategorisere dem, sætte budgetter og se, hvor pengene går hen.

**Tekniske rammer:**
- Python 3.12+, kun standardbiblioteket (`sqlite3` til data, `argparse` til CLI)
- `pytest` til tests i `produkt/tests/`
- Kør tests: `python -m pytest produkt`

Se [`opgaver/`](../opgaver/) for de idéer, der er sendt gennem fabrikken.
